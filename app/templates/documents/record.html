This pack includes manifest.sha256, a plain listing of every file above and the digest recorded for it at the time this log was produced. An investigator or auditor who needs to confirm nothing in this pack has been altered since filing can copy both into an empty directory and run:

sha256sum -c manifest.sha256

Each line prints OK for a file that still matches what was recorded here; any other result names a file that no longer does, which is the fact that matters on a record kept under a legal retention duty. manifest.sha256 is written in the standard GNU coreutils layout — the 64-character hash, two spaces, then the filename, one file per line — which is simply the layout sha256sum itself requires, not a format devised for this document.
